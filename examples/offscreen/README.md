# Offscreen

Render-to-texture with MSAA resolve for post-processing effects.

**Demonstrates:**
- Offscreen framebuffer creation with color and depth attachments
- Rendering scene to texture instead of swapchain
- MSAA (4x) with resolve to single-sample target
- Using rendered texture as input for another pass
- Multi-pass rendering pipeline
- Mirror/reflection effects using offscreen render

**Controls:**
- Mouse drag: Rotate camera
- Scroll wheel: Zoom in/out
- ESC: Exit

# Dynamic Uniform Buffer

Dynamic UBO offsets for efficient batched rendering of multiple objects.

**Demonstrates:**
- Single large uniform buffer containing multiple object data blocks
- Dynamic offset binding to select per-object data at draw time
- Proper alignment for dynamic uniform buffer offsets
- Efficient batched rendering pattern without descriptor set updates
- Grid of rotating cubes with unique transforms

**Controls:**
- Mouse drag: Rotate camera
- Scroll wheel: Zoom in/out
- ESC: Exit

# Specialization Constants

Shader specialization for compile-time variants from a single shader source.

**Demonstrates:**
- Specialization constants in HSL shaders
- Creating multiple pipeline variants from one shader
- Runtime pipeline selection based on user input
- Different lighting models (Phong, Toon, Textured) via specialization
- Efficient shader variant compilation

**Controls:**
- 1/2/3: Switch lighting mode (Phong/Toon/Textured)
- Mouse drag: Rotate camera
- Scroll wheel: Zoom in/out
- ESC: Exit

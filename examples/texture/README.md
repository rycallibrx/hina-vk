# Texture

Textured cube rendering with KTX texture loading and mipmaps.

**Demonstrates:**
- Loading KTX textures with `hina_ktx_load_texture_file`
- Mipmap generation and sampling
- Combined image sampler descriptors
- Bind groups for scene uniforms and texture sampling
- Phong lighting with textured surface

**Controls:**
- Mouse drag: Rotate camera
- Scroll wheel: Zoom in/out
- ESC: Exit

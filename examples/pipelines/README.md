# Pipelines

Multiple pipeline variants with different shaders and rendering modes.

**Demonstrates:**
- Creating multiple pipelines from different shader sources
- Pipeline state variations (polygon mode, shading model)
- Runtime pipeline switching based on user input
- Phong shading, toon shading, and wireframe modes
- UV sphere mesh rendering

**Controls:**
- 1: Phong shading
- 2: Toon shading
- 3: Wireframe mode
- Mouse drag: Rotate camera
- Scroll wheel: Zoom in/out
- ESC: Exit

# Triangle

Basic indexed triangle with MVP transform. The "hello world" of Vulkan rendering with HinaVK.

**Demonstrates:**
- Window setup with SDL2
- Basic render pass and pipeline creation
- Vertex and index buffer creation
- HSL shader with vertex input and uniforms
- Uniform buffer for projection/view/model matrices
- Depth buffer handling

**Controls:**
- Mouse drag: Rotate camera
- Scroll wheel: Zoom in/out
- ESC: Exit

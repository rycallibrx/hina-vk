# Descriptor Sets

Bind groups with per-object uniforms, texturing, and 4x MSAA rendering.

**Demonstrates:**
- Multiple bind groups (scene-level and per-object)
- Transient bind group allocation for per-frame data
- MSAA rendering (4x samples) with automatic resolve
- Multiple cubes with different textures per object
- Uniform buffer alignment for per-object data

**Controls:**
- Mouse drag: Rotate camera
- Scroll wheel: Zoom in/out
- ESC: Exit
